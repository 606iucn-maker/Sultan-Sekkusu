تسجيل دخول المشرف

كيف أنشئ الرمز (مرة واحدة فقط)؟
  1. ادخل على github.com ← صورتك ← Settings.
  2. في آخر القائمة: Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  3. اكتب أي اسم، وفي Expiration اختر مدة طويلة.
  4. في Repository access اختر Only select repositories ثم مستودع الموقع.
  5. في Permissions ← Repository permissions اجعل Contents = Read and write.
  6. اضغط Generate token وانسخ الرمز والصقه هنا. لا تشاركه مع أحد.

إضافة محتوى جديد

أضف قسمًا أولًا من تبويب «الأقسام».
يدعم روابط التضمين من MEGA (https://mega.nz/embed/... أو الصيغة ID#KEY) ويوتيوب وGoogle Drive وVimeo وروابط mp4 المباشرة، وتُشغَّل داخل الموقع. الفيديوهات الكبيرة (مثل 1.5 جيجا) ارفعها هناك والصق الرابط.
يمكنك اختيار عدة فيديوهات معاً. الحد الأقصى 95 ميجابايت لكل فيديو. للفيديوهات الأكبر استخدم «رابط فيديو» من يوتيوب أو Google Drive.
ضع رابط كل فيديو في سطر مستقل. يدعم روابط MEGA ويوتيوب وGoogle Drive وVimeo. يظهر الفيديو الأول، ثم هذه الفيديوهات تحته، ثم الصور.
